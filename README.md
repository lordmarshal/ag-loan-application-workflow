# Agricultural Loan Application Workflow Modernization

**Portfolio project by Blessing Adeniyi, PMP · Role: Domain Lead, Loan Application Workflow**

> This is a simulated project built for my professional portfolio. Prairie Harvest Credit is a fictional agriculture lender, and all names, figures and data are invented. The project shows how a Domain Lead owns and improves a loan application workflow end to end.

## The problem

Farmers applying for credit waited **21 business days** for a decision. 42% of applications arrived incomplete, relationship managers (RMs) spent 6.5 hours per application chasing documents and retyping data, and the Customer Service Centre took about 2,300 "where is my application?" calls a month. Discovery showed that **12 of the 21 days** were spent collecting and chasing documents.

## The approach

As Domain Lead, I set the vision and OKRs, mapped the current and future state process with lending, Credit and Compliance, prioritized features with WSJF, and guided two Agile squads through three releases in 2025, with compliance guardrails built in: identity and beneficial ownership checks, privacy impact assessments, no automated credit decisions, full audit trail, and English and French service.

## Results (Q4 2025 vs Q4 2024)

| Measure | Before | Target | After |
|---|---|---|---|
| Time to credit decision | 21 days | 10 | **11 days** |
| Applications complete the first time | 58% | 85% | **84%** |
| Application customer satisfaction | 68% | 80% | **81%** |
| RM admin hours per application | 6.5 | 4.0 | **4.1** |
| Data entry errors | 7% | under 2% | **1.6%** |
| Status calls per month | 2,300 | 1,150 | **1,050** |

About **33,600 RM hours a year** freed for advising farmers.
